# Actualidad local

Alternativa visual a Diario editorial, pendiente de revisión con el cliente. No modifica el sitio publicado.

- Logo original lateral, sin redibujarlo; clima de muestra y reloj real conservados.
- Apertura horizontal con título sans de Archivo y fotografía contenida a la derecha.
- Dos noticias secundarias debajo y últimas noticias en una franja horizontal; se elimina la columna lateral en portada.
- Producción propia en una banda grafito con fotografía pequeña del equipo.
- Comparte la lógica del prototipo editorial para evitar duplicar arreglos de navegación, búsqueda y cabecera dinámica.

Los contenidos son de archivo o de demostración. La agrupación Entrevistas sigue siendo una propuesta editorial. Las funciones no envían datos ni publican contenidos.
